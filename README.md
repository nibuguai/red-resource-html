# 红色资源名录检索与展示系统

一个基于 HTML 的红色资源名录检索与展示系统，集成了高德地图，支持搜索、筛选和地图展示功能。

## 功能特点

- 🔍 资源名录搜索与检索
- 🗺️ 高德地图集成，支持地理位置展示
- 📋 多条件筛选
- 📱 响应式布局设计

## 使用方法

直接在浏览器中打开 `red-resource.html` 即可使用。

## 项目结构

```
red-resource-html/
├── red-resource.html    # 主页面
├── 2.png                # 图片资源
├── 天坛.jpg             # 图片资源
├── 天坛2.jpg            # 图片资源
└── README.md            # 项目说明
```

## 技术栈

- HTML5 / CSS3 / JavaScript
- 高德地图 API (AMap 2.0)
